A program that writes an original out-of-office auto-reply to /output/entry.txt: the sender is on leave until Monday, having run out of enthusiasm somewhere around unread message 300, and will reply in the order messages arrived — with a fresh pot of coffee.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
